📘 Lumina – ReactJS Portfolio Template Documentation

Created by Sobia Soomro - Frontend Web Developer

Introduction

Thank you for choosing Lumina! I created this template to help developers like you showcase your work and tell your story online in a beautiful, professional way. Let’s get started with setup and customization!

1. Requirements

  • Node.js (LTS version recommended)
  • npm or yarn
  • Code editor (VS Code suggested)

2. Installation Steps

  1. Extract the downloaded ZIP file.
  2. Open the folder in your code editor (e.g., VS Code).
  3. Run the following commands:
npm install
npm start

The app will open in your browser at http://localhost:3000.

3. Folder Structure

lumina/
├─ src/
│  ├─ components/
│  ├─ pages/
│  ├─ assets/
│  └─ data/
├─ public/
├─ documentation/
└─ package.json

4. Customization Guide

Change Profile Info

Open src/data/profileData.js and update your name, title, and bio.

Update Projects

Edit src/data/projectsData.js to add or modify your projects.

Change Theme or Colors

In src/styles/variables.css, update color variables for light or dark mode.

Update Social Links

Modify src/data/socialLinks.js to update your links.

Replace Images

Replace images inside src/assets/ or public/images/.

5. Build and Deployment

To create an optimized production build, run:

npm run build

Upload the generated build/ folder to Netlify, Vercel, or your hosting provider.
