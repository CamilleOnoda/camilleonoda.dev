# Lumina – React Portfolio Template

Lumina is a modern and responsive **React portfolio template** built with **React**, **Framer Motion**, and **React Router**.
It’s designed to help developers and designers quickly create professional portfolio websites with elegant animations and a clean UI.

---

## Features

- Built with React (v19)
- Smooth animations using Framer Motion
- Responsive and modern UI
- Reusable and well-organized components
- Light/Dark theme support
- Easy customization

---

## Requirements

Before starting, make sure you have:

- Node.js (LTS version recommended)
- npm or yarn
- Code editor (VS Code suggested)

---

## Installation

1. **Download or clone** the repository
2. Open the project folder in your editor
3. Run the following commands:

```bash
npm install
npm start
```
